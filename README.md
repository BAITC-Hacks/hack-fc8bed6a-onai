# Классификатор обращений

Небольшой скрипт читает пять обращений из `messages.txt`, определяет их категорию и печатает черновик ответа на русском языке. Решение не требует API-ключей и внешних библиотек: категории определяются по простым ключевым словам.

## Запуск

Нужен Python 3. Запустите из корня репозитория:

```powershell
python classify_messages.py
```

## Результат

Для каждого сообщения выводятся исходный текст, одна из категорий `справка`, `жалоба` или `другое`, а также готовый черновик ответа. На предоставленных обращениях скрипт определяет запросы о справке и парковке как «справка», сообщения об очереди и Wi-Fi — как «жалоба», а запись на консультацию — как «другое».

Правила и ответы находятся в `classify_messages.py`; их легко дополнить новыми ключевыми словами или шаблонами.
